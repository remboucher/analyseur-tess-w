OPTION 1 : DÉPLOIEMENT SUR NETLIFY (Recommandé - 5 minutes)
═══════════════════════════════════════════════════════════════

ÉTAPE 1 : Créer un repo GitHub
-------------------------------

A. Via l'interface GitHub.com :

1. Aller sur https://github.com
2. Se connecter
3. Cliquer sur le "+" en haut à droite → "New repository"
4. Nom du repo : analyseur-tess-w
5. Visibilité : Public (ou Private)
6. NE PAS cocher "Add a README file"
7. Cliquer "Create repository"

B. Via le Terminal (Mac) :

1. Ouvrir le Terminal
2. Naviguer vers ce dossier :
   cd [chemin vers]/analyseur-tess-w-deploy

3. Initialiser Git :
   git init
   git add .
   git commit -m "Initial commit - Analyseur TESS-W v6.0"

4. Lier au repo GitHub :
   git remote add origin https://github.com/remboucher/analyseur-tess-w.git
   git branch -M main
   git push -u origin main

ÉTAPE 2 : Déployer sur Netlify
-------------------------------

1. Aller sur https://netlify.com
2. Se connecter avec GitHub
3. Cliquer "Add new site" → "Import an existing project"
4. Choisir "Deploy with GitHub"
5. Autoriser Netlify
6. Sélectionner votre repo "analyseur-tess-w"
7. Configuration (normalement auto-détectée) :
   - Build command: npm run build
   - Publish directory: build
8. Cliquer "Deploy site"
9. Attendre 2-3 minutes
10. TERMINÉ ! 🎉

Votre site sera accessible à :
https://random-name-12345.netlify.app

ÉTAPE 3 : Personnaliser l'URL (optionnel)
------------------------------------------

1. Dans Netlify, aller dans "Site settings"
2. Cliquer "Change site name"
3. Entrer : analyseur-tess-w
4. Sauvegarder

Nouvelle URL :
https://analyseur-tess-w.netlify.app

OPTION 2 : UTILISATION EN LOCAL (Mac)
═══════════════════════════════════════════════════════════════

PRÉREQUIS : Node.js
-------------------

Vérifier si installé :
node --version

Si pas installé :
1. Aller sur https://nodejs.org
2. Télécharger la version LTS
3. Installer
4. Redémarrer le Terminal

INSTALLATION
------------

1. Ouvrir le Terminal
2. Naviguer vers ce dossier :
   cd [chemin vers]/analyseur-tess-w-deploy

3. Installer les dépendances :
   npm install

   (Attendre 1-2 minutes)

4. Lancer l'application :
   npm start

L'app s'ouvre automatiquement à http://localhost:3000

UTILISATION QUOTIDIENNE
-----------------------

1. Ouvrir le Terminal
2. cd [chemin vers]/analyseur-tess-w-deploy
3. npm start
4. Utiliser l'app dans le navigateur
5. Pour arrêter : Ctrl+C dans le Terminal

OPTION 3 : DÉPLOIEMENT SUR VERCEL

RÉSOLUTION DE PROBLÈMES
═══════════════════════════════════════════════════════════════

ERREUR : "npm: command not found"
→ Node.js n'est pas installé. Voir PRÉREQUIS ci-dessus.

ERREUR : "port 3000 already in use"
→ Une autre app utilise le port.
   Solution : PORT=3001 npm start

ERREUR DE BUILD sur Netlify
→ Vérifier que package.json contient : "typescript": "4.9.5"
→ C'est déjà le cas dans ce projet ✅

L'app ne se charge pas
→ Vider le cache du navigateur (Cmd+Shift+R sur Mac)
→ Vérifier la console du navigateur (F12)
